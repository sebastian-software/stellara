# Support

Stellara is maintained as an open-source project without a support service-level agreement.

Use GitHub Issues for:

- reproducible defects in a supported release;
- focused feature proposals;
- documentation corrections.

Before opening an issue, search for existing reports and include the Stellara version, relevant configuration with secrets removed, expected behavior, actual behavior, and a minimal reproduction when possible.

GitHub Discussions and the repository wiki are disabled. General deployment consulting, upstream provider support, and incident response for individual installations are outside the project's support commitment.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
