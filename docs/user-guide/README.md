# Stellara-Benutzerhandbuch

Willkommen im User-Guide von Stellara. Hier findest du alles, was du als Nutzer brauchst, um Stellara in deiner LLM-App einzurichten und produktiv zu verwenden.

## Lese-Reihenfolge

1. [Stellara in LLM-Apps einbinden](llm-clients-einbinden.md) — Einrichtung in Claude Desktop, ChatGPT Connectors und anderen MCP-Clients, Authentifizierung (OAuth 2.1/PKCE und direkter Bearer-Token), Schnelltest per curl sowie Hilfe bei typischen Fehlerfällen.
2. [Verfügbare Tools](tools.md) — vollständige Liste aller angebotenen Tools und was jedes davon tut.

Fragen zur internen Funktionsweise, zum Betrieb oder zur Mitarbeit am Projekt beantwortet der [Developer-Guide](../developer-guide/) bzw. die [Operations-Doku](../operations/).
