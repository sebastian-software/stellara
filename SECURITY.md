# Security Policy

## Supported versions

Security fixes target the latest published Stellara release. Older releases may require an upgrade before a fix is available.

## Report a vulnerability

Use GitHub's **Report a vulnerability** action in the repository Security tab. This creates a private vulnerability report that repository owners can investigate without disclosing the issue publicly.

Do not report vulnerabilities through public issues, pull requests, discussions, or social media. Include the affected version, impact, reproduction steps, and any suggested mitigation when available. Avoid accessing data that does not belong to you and stop testing if it could disrupt a third-party service.

The project does not promise a fixed response or remediation time. Repository owners will coordinate disclosure and publication through a GitHub Security Advisory when appropriate.
